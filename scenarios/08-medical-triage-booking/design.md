# 患者来电分诊与预约设计

## 定位

优先级 P8。只做受控的演示版，医疗安全和真实预约系统是上线前置条件。

## 目标流程

Agent 识别来电目的，收集有限的预约信息，回答固定营业时间/流程 FAQ；遇到紧急症状、诊断请求或无法判断的情况，立即提示紧急医疗渠道或人工升级。

## 第一版范围

- 渠道：Web/RTC 模拟来电。
- 数据：固定 FAQ 和模拟预约时段。
- 工具：读取模拟时段、提交人工预约请求。
- 暂不做：诊断、处方续配、真实患者系统、真实 SIP/IVR。

## 安全边界

Agent 不进行诊断，不给出个体化医疗结论，不声称已完成真实预约；紧急情况优先给出当地急救/人工渠道提示。
